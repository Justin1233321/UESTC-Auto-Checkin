1微信扫码授权

先点下面的按钮打开授权页，用你本人的微信扫码确认。

扫码完成后，回到授权页按 F12：
Application（应用程序）→ 左侧「Cookie」→ 点开 static.pc.yyb.qq.com
在右侧列表找到 openid、accesstoken、refreshtoken， 双击 Value 复制，填到下面。

注意域名不要选错。要选 static.pc.yyb.qq.com， 不是 idas.uestc.edu.cn（那个下面是指纹，第 4 步才用）。

复制完立刻关闭那个授权页面。同一组凭据只能有一个客户端保活。

3宿舍坐标

必须在宿舍现场取。围栏半径约 150 米，站在宿舍里取的值才可靠。

取法：在宿舍用浏览器打开 晚安成电页面 并登录 → F12 → Network → 过滤 reverse → 找到 map/reverse?lat=...&lng=...，URL 里的数字就是坐标。
如果页面只显示「登录无效或已过期」（白屏、中间一个小黑条）， 说明这个微应用页拿不到你的登录态。先正常进入一次「成电智慧学工」 （PC 微信小程序或手机上打开），再回到这个网页刷新，就能正常显示地图了。

这不是账号有问题，是平台要求先经过一次端内入口授权。你的账号密码在门户登录时已经验证过了。

4统一身份认证

打卡平台登录用。

指纹决定登录时要不要短信验证。用平时打卡的那个浏览器登录 jzsz.uestc.edu.cn， 然后 F12 → Application → Cookies → https://idas.uestc.edu.cn → 找 MULTIFACTOR_BROWSER_FINGERPRINT。 它是 HttpOnly，document.cookie 看不到。
